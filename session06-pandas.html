From NumPy to pandas

NumPy: fast arrays, but columns have no names and one type for everything.

pandas adds:

  • named columns, each with its own type (numbers, text, dates)
  • a row index (labels for rows)
  • reading / writing CSV, Excel, …; handling missing values; grouping

Options you will need

pd.read_csv(
    "results.csv",
    sep=";",               # separator: ",", ";", "\t"
    decimal=",",           # decimal comma (European exports)
    skiprows=3,            # skip header lines written by the solver
    usecols=["t", "F"],    # read only some columns
    na_values=["n/a", "-"],# extra strings that mean "missing"
    index_col="run_id",    # use a column as the row index
)
pd.read_excel("results.xlsx", sheet_name="Runs")   # needs openpyxl

If every column came in as one wide text column, the separator is wrong. If numbers are text like "12,5", the decimal sign is wrong.

What to check on every new dataset

  1. number of rows and columns — as expected?
  2. column types — numbers read as numbers?
  3. ranges — min / max physically plausible? units?
  4. missing values — info() non-null counts
  5. ID column — unique?

Changing data

New columns

df["nominal_stress_MPa"] = 6 * df["load_N"] * 150 / (40 * df["thickness_mm"] ** 2)
df["Kt"] = df["max_stress_MPa"] / df["nominal_stress_MPa"]
df["passes"] = df["safety_factor"] >= 1.5
df["E_MPa"] = df["E_GPa"] * 1000
