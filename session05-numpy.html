Why NumPy?

import numpy as np
import time

t = list(range(1, 1_000_001))
start = time.perf_counter()
s_list = [6 * 1500 * 150 / (40 * x ** 2) for x in t]
t_list = time.perf_counter() - start

t_arr = np.arange(1, 1_000_001)
start = time.perf_counter()
s_arr = 6 * 1500 * 150 / (40 * t_arr ** 2.0)
t_np = time.perf_counter() - start
print(f"list: {t_list*1000:.0f} ms   numpy: {t_np*1000:.0f} ms   ({t_list/t_np:.0f}× faster)")
list: 45 ms   numpy: 3 ms   (14× faster)
  • one operation on the whole array, executed in compiled code
  • the basis of pandas, scikit-learn and PyTorch

Creating arrays

print(np.arange(0, 1, 0.25))             # like range, also decimals

print(np.zeros(3), np.ones(3))

[0.   0.25 0.5  0.75]

  • one array = one type for all elements (int64, float64, bool, …)
  • np.linspace is the one you want for “N points between min and max”

Vectorised calculations

t = np.linspace(8, 20, 7)            # mm
F = 1500                             # N
stress = 6 * F * 150 / (40 * t ** 2)
sf = 355 / stress
print(np.round(stress, 1))
print(np.round(sf, 2))
[527.3 337.5 234.4 172.2 131.8 104.2  84.4]
[0.67 1.05 1.51 2.06 2.69 3.41 4.21]
  • arithmetic works element by element
  • np.sqrt, np.exp, np.log, np.sin, np.abs, … too

Your bracket function works on arrays — for free

def bending_stress(F, t, L=150, b=40):
    return 6 * F * L / (b * t ** 2)

print(bending_stress(1500, 12))                       # one number
print(bending_stress(1500, np.array([10, 12, 14])))   # array of thicknesses
print(bending_stress(np.array([1000, 2000]), np.array([10, 14])))  # pairs
234.375
[337.5        234.375      172.19387755]
[225.         229.59183673]

Write functions with plain arithmetic and NumPy functions (np.sqrt, not math.sqrt) — then they work for one design and for 10 000 designs.

Shape and dimensions

2-D arrays: a table of numbers

X = np.array([[12.0, 4.5, 1500],
              [10.0, 2.0, 2500],
              [16.0, 6.0, 1000]])      # 3 runs × 3 inputs
print(X.shape, X.ndim)
print(X[0])        # first row  = first run
print(X[:, 2])     # third column = all loads
(3, 3) 2
[  12.     4.5 1500. ]
[1500. 2500. 1000.]
  • shape = (rows, columns)
  • this is exactly the X matrix of Module 3: rows = runs, columns = features

Boolean masks: select by condition

stress = bending_stress(1500, t)
mask = stress < 355 / 1.5          # SF >= 1.5
print(mask)
print(t[mask])                     # thicknesses that pass
print(mask.sum(), "of", mask.size, "pass")
[False False  True  True  True  True  True]
[12. 14. 16. 18. 20.]
5 of 7 pass
  • comparisons on arrays give arrays of True / False
  • array[mask] keeps only the True positions
  • combine with & (and), | (or), ~ (not) — with brackets:
print(t[(t > 10) & (t < 18)])
[12. 14. 16.]

np.where: choose element by element

verdict = np.where(stress < 355 / 1.5, "OK", "FAIL")
print(verdict)
capped = np.clip(stress, None, 355)      # limit values to a range
print(np.round(capped))
['FAIL' 'FAIL' 'OK' 'OK' 'OK' 'OK' 'OK']
[355. 338. 234. 172. 132. 104.  84.]

Broadcasting

Combining arrays of different shapes

All thicknesses × all loads in one step:

t = np.array([10, 12, 16, 20])           # shape (4,)
F = np.array([[1000], [2000], [3000]])   # shape (3, 1)
S = bending_stress(F, t)                 # shape (3, 4)
print(np.round(S))
[[225. 156.  88.  56.]
 [450. 312. 176. 112.]
 [675. 469. 264. 169.]]
  • NumPy stretches dimensions of size 1 to match: (3, 1) with (4,) → (3, 4)
  • rows = loads, columns = thicknesses

A design chart in three lines

import matplotlib.pyplot as plt
t = np.linspace(8, 20, 50)
for F in [1000, 2000, 3000]:
    plt.plot(t, 355 / bending_stress(F, t), label=f"F = {F} N")
plt.axhline(1.5, color="k", ls="--"); plt.xlabel("thickness, mm"); plt.ylabel("safety factor")
plt.legend(); plt.show()

Random numbers

Random sampling plans

rng = np.random.default_rng(seed=42)      # seed → reproducible
n = 5
t = rng.uniform(8, 20, n)
F = rng.uniform(200, 3000, n)
plan = np.column_stack([t, F])
print(np.round(plan, 1))
[[  17.3 2931.7]
 [  13.3 2331.2]
 [  18.3 2401. ]
 [  16.4  558.7]
 [   9.1 1461.1]]
  • rng.uniform, rng.normal, rng.integers, rng.choice
  • always set a seed when results must be reproducible

Monte Carlo: scatter in the inputs

Thickness tolerance ±0.3 mm (= 3σ), load scatter 10 % (1σ):

rng = np.random.default_rng(1)
N = 100_000
t = rng.normal(12, 0.1, N)
F = rng.normal(1500, 150, N)
sf = 355 / bending_stress(F, t)
print(f"mean SF {sf.mean():.2f}, 1st percentile {np.percentile(sf, 1):.2f}")
print(f"P(SF < 1.5) = {(sf < 1.5).mean():.2%}")
mean SF 1.53, 1st percentile 1.22
P(SF < 1.5) = 46.32%

100 000 evaluations in milliseconds — because the formula is cheap. With an FEM solver each point costs minutes. That is exactly why we want surrogate models.

Summary

  • NumPy arrays: one type, any shape; arithmetic works on the whole array
  • shape, axis=0 (down columns) vs axis=1 (across rows)
  • select with slices and boolean masks; np.where for element-wise choice
  • broadcasting combines arrays of different shapes
  • default_rng(seed) for reproducible random numbers
