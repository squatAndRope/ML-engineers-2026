def bending_stress(F, t, L=150, b=40):
    """Max bending stress of a rectangular cantilever, MPa."""
    return 6 * F * L / (b * t ** 2)

for t in [10, 12, 14]:

Lists

A list holds many values in order

thicknesses = [8, 10, 12, 16, 20]          # mm
print(len(thicknesses))
print(thicknesses[0], thicknesses[-1])     # first, last
print(thicknesses[1:3])                    # slice: index 1 and 2
5
8 20
[10, 12]
  • indexes start at 0; negative indexes count from the end
  • slice a[start:stop] — stop is not included (like range)

Changing a list

loads = [500, 1000, 1500]
loads.append(2000)          # add at the end
loads[0] = 750              # replace an item
loads.remove(1000)          # remove by value
print(loads)
print(sorted([3, 1, 2]), max(loads), min(loads), sum(loads))
[750, 1500, 2000]
[1, 2, 3] 2000 750 4250
  • lists are mutable — you can change them after creating them
  • sorted(), max(), min(), sum(), len() work on any list of numbers

Building a list in a loop

stresses = []
for t in thicknesses:
    stresses.append(bending_stress(1500, t))
print([round(s, 1) for s in stresses])
[527.3, 337.5, 234.4, 131.8, 84.4]

The same in one line — a list comprehension:

stresses = [bending_stress(1500, t) for t in thicknesses]
ok = [t for t in thicknesses if 355 / bending_stress(1500, t) >= 1.5]
print(ok)
[12, 16, 20]

Looping over two lists together

for t, s in zip(thicknesses, stresses):
    print(f"{t:>3} mm  {s:7.1f} MPa")
  8 mm    527.3 MPa
 10 mm    337.5 MPa
 12 mm    234.4 MPa
 16 mm    131.8 MPa
 20 mm     84.4 MPa
for i, t in enumerate(thicknesses):
    print(i, t)
0 8
1 10
2 12
3 16
4 20
  • zip(a, b) — walk through two lists side by side
  • enumerate(a) — get the position and the value

Tuples and dictionaries

Tuples: fixed records

design = (12.0, 4.5, 1500)        # thickness, fillet radius, load
t, r, F = design                   # unpacking
print(t, r, F)
# design[0] = 14   -> TypeError: tuples cannot be changed
12.0 4.5 1500
  • like a list, but immutable — good for things that belong together and should not change
  • you already met them: a function returning stress, deflection returns a tuple

Dictionaries: values by name

steel = {"name": "S355", "yield_MPa": 355, "E_GPa": 210, "density": 7850}
print(steel["yield_MPa"])
steel["E_GPa"] = 205           # change
steel["weldable"] = True       # add a new key
print(steel.keys())
355
dict_keys(['name', 'yield_MPa', 'E_GPa', 'density', 'weldable'])
  • {key: value, ...} — look things up by key, not by position
  • keys are usually strings; values can be anything

Dictionaries in practice

yield_strength = {"S235": 235, "S355": 355, "S460": 460}

for grade, fy in yield_strength.items():
    sf = fy / bending_stress(1500, 12)
    print(f"{grade}: SF = {sf:.2f}")

print(yield_strength.get("S690", "unknown grade"))
S235: SF = 1.00
S355: SF = 1.51
S460: SF = 1.96
unknown grade
  • .items() gives key–value pairs
  • .get(key, default) avoids an error when the key is missing

A calculation run as a dictionary

run = {"run_id": "R001", "thickness_mm": 12, "load_N": 1500}
run["stress_MPa"] = bending_stress(run["load_N"], run["thickness_mm"])
run
{'run_id': 'R001', 'thickness_mm': 12, 'load_N': 1500, 'stress_MPa': 234.375}

A list of such dictionaries = a table:

runs = [
    {"run_id": "R001", "thickness_mm": 12, "load_N": 1500},
    {"run_id": "R002", "thickness_mm": 10, "load_N": 2500},
]
for r in runs:
    print(r["run_id"], round(bending_stress(r["load_N"], r["thickness_mm"]), 1))
R001 234.4
R002 562.5

This is exactly the shape of the data in Module 2. pandas will make it much more comfortable.

Sets: unique values

materials_used = ["S355", "S235", "S355", "S355", "S460"]
unique = set(materials_used)
print(unique, len(unique))
print("S690" in unique)
{'S235', 'S460', 'S355'} 3
False
  • no duplicates, no order
  • fast in checks; useful for “which different values do I have?”

Which structure when?

Structure Syntax Ordered Changeable Typical use
list [1, 2, 3] yes yes series of values
tuple (1, 2, 3) yes no one fixed record
dict {"a": 1} by insertion yes values by name
set {1, 2, 3} no yes unique values

Working with code: errors

Errors are normal

loads = [500, 1000, 1500]
print(loads[3])
---------------------------------------------------------------------------
IndexError                                Traceback (most recent call last)
Cell In[14], line 2
      1 loads = [500, 1000, 1500]
----> 2 print(loads[3])

IndexError: list index out of range

How to read a traceback:

  1. go to the last line: the error type and message
  2. look one line up: where it happened
  3. ask: what value did Python have at that moment?

The errors you will see most

Error Usual reason
SyntaxError missing :, bracket or quote
IndentationError wrong spaces at the start of a line
NameError a typo in a name, or the variable was never created (cell not run?)
TypeError wrong type, e.g. "12" + 3
IndexError list position that does not exist
KeyError dictionary key that does not exist
ZeroDivisionError dividing by zero
ValueError right type, wrong value, e.g. float("abc")

Debugging tools you already have

def safety_factor(F, t):
    s = bending_stress(F, t)
    print("DEBUG stress =", s)          # look inside
    return 355 / s

safety_factor(1500, 12)
DEBUG stress = 234.375
1.5146666666666666
  • print() intermediate values; type(x) when in doubt
  • test with simple numbers you can check by hand
  • assert — stop if something is not as expected:
t = -12
assert t > 0, f"thickness must be positive, got {t}"
---------------------------------------------------------------------------
AssertionError                            Traceback (most recent call last)
Cell In[16], line 2
      1 t = -12
----> 2 assert t > 0, f"thickness must be positive, got {t}"

AssertionError: thickness must be positive, got -12

Handling expected problems: try / except

values = ["12.5", "13", "n/a", "11.8"]
clean = []
for v in values:
    try:
        clean.append(float(v))
    except ValueError:
        print(f"skipped bad value: {v!r}")
print(clean)
skipped bad value: 'n/a'
[12.5, 13.0, 11.8]

Catch only errors you expect and know how to handle. Never hide all errors with a bare except:.

Your own module

Save the functions in a file bracket.py:

# bracket.py
def bending_stress(F, t, L=150, b=40):
    return 6 * F * L / (b * t ** 2)

Then, in a notebook or another script in the same folder:

from bracket import bending_stress
bending_stress(1500, 12)

Once a formula is checked, put it in a module. Every notebook then uses the same, tested version.

Writing and reading a text file

with open("results.txt", "w") as f:
    for t in [10, 12, 14]:
        f.write(f"{t},{bending_stress(1500, t):.1f}\n")

with open("results.txt") as f:
    for line in f:
        t, s = line.strip().split(",")
        print(float(t), float(s))
10.0 337.5
12.0 234.4
14.0 172.2
  • with open(...) as f: closes the file automatically
  • "w" write (overwrites), "a" append, default "r" read
  • each line is a string: .strip(), .split(","), then convert

Good habits

  • meaningful names: stress_MPa, not x2
  • one function = one job; docstring with units
  • comments explain why, the code shows what
  • run the notebook top to bottom (Runtime → Restart and run all) before you trust it
  • style guide: PEP 8 — 4 spaces, snake_case, lines not too long

Summary

  • list [] ordered, changeable · tuple () fixed · dict {k: v} by name · set unique
  • list comprehensions: [f(x) for x in items if condition]
  • read tracebacks from the bottom; most errors are typos or wrong types
  • import modules; put checked functions in your own .py file
  • files: with open(...), lines are strings
