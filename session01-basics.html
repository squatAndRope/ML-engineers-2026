Values, types and variables

Python as a calculator

print(7 + 2, 7 - 2, 7 * 2, 7 / 2)

Variables: names for values

load_N = 1500          # tip load, N
length_mm = 150        # bracket length, mm
moment_Nmm = load_N * length_mm
moment_Nmm
225000
  • = means assign (“store the value under this name”), not “equals”
  • names: letters, digits, _; cannot start with a digit; case matters
  • # starts a comment — Python ignores it, people read it

Put the unit in the name: load_N, stress_MPa. Python does not know units — you do.

Basic types

thickness = 12.5        # float  – decimal number
n_runs = 300            # int    – whole number
material = "S355"       # str    – text
is_welded = True        # bool   – True / False

print(type(thickness), type(n_runs), type(material), type(is_welded))
<class 'float'> <class 'int'> <class 'str'> <class 'bool'>
  • the type decides what you can do with the value
  • "12" + "3" gives "123"; 12 + 3 gives 15

Converting between types

value_from_file = "355"         # text, e.g. read from a file
yield_MPa = float(value_from_file)
print(yield_MPa * 2)
print(int(7.9), round(7.9), str(42) + " runs")
710.0
7 8 42 runs
  • int(), float(), str(), bool() convert values
  • int() cuts the decimals off, round() rounds

f-strings: readable output

stress = 287.456
sf = 355 / stress
print(f"Max stress: {stress:.1f} MPa, safety factor: {sf:.2f}")
Max stress: 287.5 MPa, safety factor: 1.23
  • f"..." with {expression} inside
  • :.1f = one decimal place, :.2f = two, :.2e = scientific notation

Bending stress — our first engineering formula

For a rectangular cantilever (width b, thickness t, length L, load F):

\[\sigma = \frac{6 F L}{b\,t^2}\]

F = 1500      # N
L = 150       # mm
b = 40        # mm
t = 12        # mm
sigma_MPa = 6 * F * L / (b * t ** 2)     # N/mm² = MPa
print(f"sigma = {sigma_MPa:.1f} MPa")
sigma = 234.4 MPa

if / elif / else

sf = 1.32

if sf >= 2.0:
    print("OK, with margin")
elif sf >= 1.5:
    print("OK")
elif sf >= 1.0:
    print("Below required margin – check the design")
else:
    print("FAILURE: yield stress exceeded")
Below required margin – check the design
  • the colon : opens a block; the block is indented (4 spaces)
  • Python checks the conditions from top to bottom and runs the first that is true

Indentation matters

if sf < 1.5:
    print("Rejected")
    print("Increase thickness")
print("Check finished")

Last line always runs.

if sf < 1.5:
    print("Rejected")
print("Increase thickness")
print("Check finished")

Now “Increase thickness” is printed every time.

Other languages use { } for blocks. Python uses indentation — it is part of the syntax.

Repetition: loops

for: repeat for every item

for t in [8, 10, 12, 16, 20]:
    sigma = 6 * 1500 * 150 / (40 * t ** 2)
    print(f"t = {t:2d} mm  ->  sigma = {sigma:6.1f} MPa")
t =  8 mm  ->  sigma =  527.3 MPa
t = 10 mm  ->  sigma =  337.5 MPa
t = 12 mm  ->  sigma =  234.4 MPa
t = 16 mm  ->  sigma =  131.8 MPa
t = 20 mm  ->  sigma =   84.4 MPa
  • t takes each value in turn; the indented block runs once per value
  • [8, 10, ...] is a list — more about lists in Session 2

range(): sequences of numbers

print(list(range(5)))          # 0 .. 4
print(list(range(2, 10, 2)))   # start, stop (excluded), step
[0, 1, 2, 3, 4]
[2, 4, 6, 8]
total = 0
for load in range(500, 3001, 500):     # 500, 1000, ..., 3000 N
    total = total + load
print("sum of loads:", total)
sum of loads: 10500
  • the accumulator pattern: start with 0, add in each step

while: repeat until a condition changes

Find the smallest thickness (step 0.5 mm) that gives SF ≥ 1.5:

t = 6.0
sf = 0
while sf < 1.5:
    t = t + 0.5
    sigma = 6 * 1500 * 150 / (40 * t ** 2)
    sf = 355 / sigma
print(f"minimum thickness: {t} mm (SF = {sf:.2f})")
minimum thickness: 12.0 mm (SF = 1.51)

Use for when you know what to loop over, while when you only know when to stop. Make sure the condition can become false, or the loop never ends (in Colab: ■ stop button).

break and continue

for t in [8, 10, 12, 14, 16]:
    sigma = 6 * 1500 * 150 / (40 * t ** 2)
    if sigma > 355:
        continue            # skip this one, go to the next t
    print(f"first acceptable thickness: {t} mm")
    break                   # leave the loop
first acceptable thickness: 10 mm

Functions

Why functions?

We already typed 6 * F * L / (b * t ** 2) five times.

  • a function = a named, reusable piece of calculation
  • fewer copy-paste errors: fix the formula in one place
  • the name documents the intent: bending_stress(...)

Defining a function

def bending_stress(F, L, b, t):
    """Max bending stress of a rectangular cantilever, MPa (F in N, lengths in mm)."""
    return 6 * F * L / (b * t ** 2)

s = bending_stress(1500, 150, 40, 12)
print(f"{s:.1f} MPa")
234.4 MPa
  • def name(parameters): + indented body
  • return sends the result back; without it, the function returns None
  • the text in """...""" is a docstring: what the function does, units

Default values and keyword arguments

def bending_stress(F, t, L=150, b=40):
    return 6 * F * L / (b * t ** 2)

print(bending_stress(1500, 12))              # uses L=150, b=40
print(bending_stress(1500, 12, L=200))       # override one value
print(bending_stress(t=12, F=1500, b=50))    # keywords: any order
234.375
312.5
187.5
  • parameters with defaults go after the ones without
  • keyword arguments make calls readable: you see what each number means

Functions calling functions

def safety_factor(stress_MPa, yield_MPa=355):
    return yield_MPa / stress_MPa

def check_design(F, t):
    sf = safety_factor(bending_stress(F, t))
    status = "OK" if sf >= 1.5 else "FAIL"
    return f"F={F} N, t={t} mm: SF={sf:.2f} {status}"

print(check_design(1500, 12))
print(check_design(2500, 10))
F=1500 N, t=12 mm: SF=1.51 OK
F=2500 N, t=10 mm: SF=0.63 FAIL
  • "OK" if condition else "FAIL" — a one-line if

Returning several values

def bracket_response(F, t, L=150, b=40, E=200_000):
    stress = 6 * F * L / (b * t ** 2)
    deflection = 4 * F * L ** 3 / (E * b * t ** 3)
    return stress, deflection

s, d = bracket_response(1500, 12)
print(f"stress {s:.1f} MPa, deflection {d:.3f} mm")
stress 234.4 MPa, deflection 1.465 mm
  • 200_000 — underscores make long numbers readable
  • return a, b returns both; s, d = ... unpacks them

Variables inside functions stay inside

def area(b, t):
    result = b * t
    return result

print(area(40, 12))
# print(result)   -> NameError: 'result' is not defined
480
  • names created inside a function are local
  • pass data in through parameters, get it out with return
