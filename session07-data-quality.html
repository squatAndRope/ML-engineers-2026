Garbage in, garbage out

A surrogate model does not know that a value is wrong. It learns it.

Problem Example Effect on a model
wrong unit load in kN in some rows learns a fake relationship
typo thickness 196 mm instead of 19.6 one point pulls the fit
failed run stress = 0 “infinitely safe” designs
duplicates same run exported twice over-weights some designs, leaks into the test set
gaps missing deflection errors or silently dropped rows

Converting to numbers safely

def to_number(col):
    """Text -> float; accepts decimal commas and dots, bad values become NaN."""
    return pd.to_numeric(col.astype(str).str.replace(",", "."), errors="coerce")

clean = raw.copy()
for c in ["load_N", "max_stress_MPa"]:
    clean[c] = to_number(clean[c])

  • errors="coerce" turns anything that is not a number into NaN (missing)
  • always work on a copy — keep the raw data untouched

What to do with missing values?

Option When pandas
drop the row few rows, the value is essential (an output) dropna(subset=[...])
recompute the value can be derived from others e.g. SF = 355 / stress
fill with a known value a default really applies fillna(value)
fill with a statistic only for inputs, only with care fillna(col.median())
re-run the calculation best, if possible —

Never fill a missing output (stress, deflection) with a mean: you invent a calculation result. For training data, re-run or drop.

In our data

# E is missing in a few rows: material is the same steel, 200 GPa is a defensible nominal value

Making it repeatable

One cleaning function

def clean_bracket(path):
    """Read and clean a raw bracket export. Returns (clean DataFrame, report dict)."""
    df = pd.read_csv(path, sep=";", decimal=",")
    report = {"rows_in": len(df)}
    for c in ["load_N", "max_stress_MPa"]:
        df[c] = to_number(df[c])
    df = df.drop_duplicates()
    df.loc[df["load_N"] < 10, "load_N"] *= 1000                      # kN -> N
    df["E_GPa"] = df["E_GPa"].fillna(200.0)
    df = df[df["solver_status"] == "converged"]
    df = df[df["thickness_mm"].between(8, 20)]
    df = df.dropna(subset=["max_stress_MPa", "deflection_mm"])
    df["safety_factor"] = 355 / df["max_stress_MPa"]                  # recompute, consistent
    report["rows_out"] = len(df)
    return df.reset_index(drop=True), report

Checks that stop bad data

def validate(df):
    assert df["run_id"].is_unique, "duplicate run IDs"
    assert df.notna().all().all(), "missing values left"
    assert df["thickness_mm"].between(8, 20).all(), "thickness out of plan range"
    assert df["load_N"].between(200, 3000).all(), "load out of plan range (unit?)"
    assert (df["max_stress_MPa"] > 0).all(), "non-positive stress"
    return True

True

Summary

  • read with the right sep and decimal; check dtypes first
  • pd.to_numeric(..., errors="coerce") for mixed text/number columns
  • missing values: never invent outputs; document what you filled and why
  • duplicates: duplicated, drop_duplicates, unique IDs
  • ranges: compare with the plan and with physics; fix only what you can explain
  • one cleaning function + assert checks = repeatable
