import pandas as pd

Split – apply – combine

Question: how does the mean stress depend on the thickness class?

  split by class       apply mean        combine
  8–12 mm  → rows …  →  mean  ┐
  12–16 mm → rows …  →  mean  ├→  one small table
  16–20 mm → rows …  →  mean  ┘

That is groupby.

Grouping

Classes from continuous values: cut

df["t_class"] = pd.cut(df["thickness_mm"], bins=[8, 12, 16, 20],

agg: several statistics at once

summary = df.groupby("t_class", observed=True).agg(
    runs=("run_id", "count"),
    stress_mean=("max_stress_MPa", "mean"),
    stress_max=("max_stress_MPa", "max"),
    sf_min=("safety_factor", "min"),
    share_failed=("safety_factor", lambda s: (s < 1).mean()),
).round(2)

long = wide.melt(

Combining tables

concat: stack tables with the same columns

batch1 = df.iloc[:150]
batch2 = df.iloc[150:]
all_runs = pd.concat([batch1, batch2], ignore_index=True)
print(len(batch1), len(batch2), len(all_runs))
150 150 300
  • typical: results from several solver batches, several days, several colleagues
  • check afterwards: are IDs still unique?

merge: join by a key

materials = pd.read_csv("data/materials.csv")
materials
material yield_MPa
0 S235 235
1 S355 355
2 S460 460 
design = pd.DataFrame({"run_id": ["R001", "R002", "R003"], "material": ["S355", "S235", "S460"]})
merged = (design
          .merge(df[["run_id", "max_stress_MPa"]], on="run_id", how="left")
          .merge(materials, on="material", how="left"))
merged["sf"] = merged["yield_MPa"] / merged["max_stress_MPa"]
merged.round(2)

0 R001 S355 170.4 355 2.08
1 R002 S235 527.5 235 0.45
2 R003 S460 297.9 460 1.54

Join types

how= keeps
"inner" only keys present in both tables
"left" all rows of the left table; missing matches → NaN
"outer" all keys from both
"cross" every row with every row (all combinations) 
check = df.merge(materials, how="cross")
check["sf"] = check["yield_MPa"] / check["max_stress_MPa"]
pd.crosstab(check["material"], check["sf"] >= 1.5, normalize="index").round(2)
sf False True
material
S235 0.73 0.27
S355 0.60 0.40
S460 0.46 0.54

After a merge, always compare the number of rows before and after. Unexpected growth = duplicate keys.

Summary

  • pd.cut / pd.qcut — classes from continuous variables
  • groupby(...).agg(name=(col, func)) — split, apply, combine
  • pivot_table and crosstab — two-way summaries
  • melt (wide → long) and pivot (long → wide)
  • concat stacks, merge joins by keys; check row counts after every merge
