# Python & Data for Engineers

Quarto slides for the 22 sessions of *Fundamentals of Machine Learning for Engineers*
(1 Dec 2026 – 4 Mar 2027). Sessions 11–22 (Modules 3–4) are placeholder outlines. Published with GitHub Pages.

## Structure

| Path | What |
|------|------|
| `index.qmd` | schedule page with links to all decks |
| `data.qmd` | description of the course datasets |
| `sessionNN-*.qmd` | one reveal.js deck per session |
| `data/` | bracket datasets (generated by `scripts/make_data.py`) |
| `scripts/setup_env.sh`, `setup_env.ps1`, `requirements.txt` | course environment for participants |
| `assets/` | neutral slide theme, code highlighting, Matplotlib style |
| `_freeze/` | stored code outputs — keep it in the repo |

## Publish

```bash
git remote add origin https://github.com/squatAndRope/ML-engineers-2026.git
git push -u origin main
quarto publish gh-pages
```

If you use a different repository name, replace `ML-engineers-2026` in
`data.qmd`, `session06-pandas.qmd`, `scripts/setup_env.sh` and `scripts/setup_env.ps1`.

## Edit and preview

```bash
quarto preview session05-numpy.qmd
```

Code chunks run in Python (numpy, pandas, matplotlib, jupyter). Outputs are frozen
(`execute: freeze: auto`), so a deck is re-executed only when its `.qmd` changes.
